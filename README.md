
# ACTF – Adaptive Compression of Floating-Point Time-Series Data

An adaptive XOR-based compression approach for reducing storage requirements of floating-point time-series data while preserving numerical information.

ACTF extends the principles of existing compression algorithms such as **Gorilla** and **CHIMP** through repeated-value preprocessing, adaptive encoding categories, and refined leading and trailing zero handling.

The project implements and compares three compression techniques — Gorilla, CHIMP, and the proposed ACTF algorithm — using Python and IEEE 754 double-precision floating-point representations.

## Overview

Time-series data generated by IoT devices, industrial sensors, monitoring systems, and scientific applications grows continuously. Storing and transmitting large volumes of floating-point measurements introduces challenges in memory consumption, storage efficiency, and network bandwidth.

Traditional general-purpose compression methods do not fully exploit the temporal and bitwise similarities between consecutive floating-point values.

Existing algorithms such as Gorilla and CHIMP address this challenge using XOR-based encoding. However, their encoding strategies can be less efficient when data contains irregular bit patterns, repeated values, or varying distributions of leading and trailing zeros.

This project explores an enhanced approach through **ACTF (Adaptive Time-Series Floating-Point Compression)**, introducing adaptive encoding mechanisms to reduce redundant bits while maintaining accurate reconstruction.

## Key Features

- **Lossless-oriented compression:** Designed to preserve floating-point values during compression and decompression.
- **XOR-based encoding:** Exploits bitwise similarities between consecutive floating-point values.
- **Repeated-value preprocessing:** Detects consecutive identical values and avoids unnecessary XOR operations.
- **Adaptive encoding:** Introduces additional compact coding patterns to reduce encoding overhead.
- **Leading and trailing zero optimization:** Refines bit-level representation to minimize redundant information.
- **Comparative evaluation:** Implements Gorilla, CHIMP, and ACTF for performance analysis.
- **Compression analysis:** Evaluates compressed bitstream size, compression ratio, and reconstruction behavior.

## How It Works

The project uses the binary representation of floating-point values to identify redundancy between consecutive data points.

### XOR-Based Compression

For consecutive floating-point values, the algorithm performs a bitwise XOR operation:

`XOR = Current Value ⊕ Previous Value`

When values are similar, the XOR result often contains leading and trailing zeros. Instead of storing the complete 64-bit representation, the algorithm encodes the relevant information using compact bit patterns.

The first floating-point value is stored in its complete binary representation. Subsequent values are encoded based on their XOR patterns and the selected encoding strategy.

### Proposed ACTF Approach

ACTF builds upon Gorilla and CHIMP through three primary enhancements:

**Repeated-Value Preprocessing**

Consecutive repeated floating-point values are detected before XOR encoding. Identical values are represented using a compact encoding pattern, reducing unnecessary computations and storage overhead.

**Expanded Coding Categories**

ACTF introduces additional compact encoding patterns to reduce branch lengths and improve bit utilization compared with fixed encoding schemes.

**Refined Zero Handling**

The algorithm analyzes leading and trailing zeros to identify meaningful bit regions and encode changing portions more efficiently.

These enhancements aim to improve compression efficiency across floating-point time-series datasets.

## Algorithm Implementations

### Gorilla

Gorilla is an XOR-based lossless floating-point compression technique.

- Stores the first value using its complete 64-bit representation.
- Computes XOR between consecutive floating-point values.
- Detects leading and trailing zeros in the XOR result.
- Uses compact control bits and variable-length encoding.
- Reuses previously stored leading and trailing zero information when applicable.

### CHIMP

CHIMP extends Gorilla with more flexible encoding strategies.

- Uses XOR-based redundancy detection.
- Improves handling of leading and trailing zero patterns.
- Encodes trailing zeros conditionally.
- Uses compact representations for different XOR patterns.
- CHIMP128 extends the approach by considering a window of previous values.

### ACTF (Proposed)

ACTF introduces adaptive encoding to improve upon existing XOR-based techniques.

- Detects consecutive repeated values before compression.
- Skips redundant XOR computations for identical values.
- Introduces additional compact encoding categories.
- Refines leading and trailing zero analysis.
- Uses adaptive bit-level representation to reduce encoding overhead.

## Comparative Analysis

| Feature | Gorilla | CHIMP | ACTF |
|---|---|---|---|
| Core Technique | XOR encoding | Adaptive XOR encoding | Enhanced XOR encoding |
| Repeated-Value Preprocessing | Not explicitly used | Not explicitly used | Supported |
| Encoding Strategy | Fixed control-bit patterns | Flexible zero-based encoding | Expanded compact encoding categories |
| Leading Zero Handling | Encoded using leading-zero counts | Improved representation | Refined bit-level analysis |
| Trailing Zero Handling | Encoded using trailing-zero counts | Conditional encoding | Adaptive handling |
| Encoding Window | Previous value | Previous values; up to 128 in CHIMP128 | Previous value with preprocessing |
| Main Objective | Fast compression | Improved compression efficiency | Reduced redundancy and encoding overhead |

## Results and Performance

The project evaluates the three algorithms using floating-point time-series values and compares their compression behavior.

### Experimental Results

The report presents the following sample evaluation results:

| Metric | Gorilla | CHIMP | ACTF |
|---|---:|---:|---:|
| Original Data Size | 256 bits | 256 bits | 256 bits |
| Compressed Data Size | 247 bits | 168 bits | 168 bits |
| Compression Ratio | Approximately 3.52% | 34.38% | 34.38% |

The sample results demonstrate that CHIMP and ACTF achieve a smaller encoded representation than Gorilla for the tested input.

ACTF achieves the same reported compression ratio as CHIMP in this particular sample, while introducing additional adaptive encoding mechanisms.

### Reported Performance Improvements

The project report also describes broader experimental findings across IoT and server time-series datasets:

- Average compression ratio improvement of **12.25%**.
- Reported computational efficiency improvement of **27.21%** in compression and decompression compared with Gorilla and CHIMP.

These reported improvements refer to the broader evaluation described in the methodology section and should be distinguished from the individual sample output above.

### Reconstruction and Accuracy

The algorithms are designed around lossless floating-point encoding and reconstruction.

The project evaluates decompression by comparing reconstructed values with the original input. The report describes successful reconstruction for the demonstrated Gorilla and CHIMP examples; it also notes near-lossless quality in its ACTF experimental discussion.

## Limitations

- The current implementation focuses on 64-bit double-precision floating-point values.
- Compression efficiency may decrease for highly unpredictable data with limited temporal redundancy.
- Adaptive encoding can introduce additional computational overhead compared with simpler encoding strategies.
- Entropy coding techniques such as Huffman or arithmetic coding are not currently integrated.
- Hardware-level optimization and real-time streaming support have not yet been implemented.
